# 🌤️ Weather App (React + TailwindCSS)

A simple and modern **Weather App** built with **React** and **TailwindCSS** — powered by the **OpenWeather API**.  
You can search for any city in the world and instantly see real-time weather details such as temperature, humidity, and wind speed.  
The background dynamically changes between **day/night themes** based on the local time of the city.

---

## 🚀 Features

- 🔍 Search for any city
- 🌡️ Real-time temperature, humidity, and wind data
- 🌇 Dynamic background based on day or night
- ☁️ Weather icons update automatically (clear, cloudy, rain, etc.)
- 📱 Fully responsive UI (mobile-first)
- ⚡ Built with React + TailwindCSS for performance and speed
- ❌ Graceful handling of invalid cities

---

## 🧩 Tech Stack

- ⚛️ [React (Vite)](https://vitejs.dev/)

## 🛠️ Installation & Setup

Follow these steps to run the project locally 👇

### 1️⃣ Clone the repository
```bash
git clone https://github.com/yourusername/weather-app.git
cd weather-app
```

### 2️⃣ Install dependencies
```bash
npm install
```

> 💡 This command automatically installs all required packages (including **React**, **TailwindCSS**, and others) and creates the `node_modules` folder — no need to install Tailwind manually.

### 3️⃣ Run the app
```bash
npm run dev
```

Then open your browser and go to:
```
http://localhost:5173/
```
